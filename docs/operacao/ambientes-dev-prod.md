# Ambientes DEV/PROD

- `application-dev.yml`: parametros locais de desenvolvimento.
- `application-prod.yml`: parametros para producao.
- Segredos devem ficar fora do repositorio.
- Supabase Auth: veja `docs/operacao/auditoria-auth-supabase.md` antes de
  ativar cadastro/login/recuperacao em ambiente compartilhado ou produtivo.
